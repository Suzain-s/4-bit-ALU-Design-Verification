4-bit ALU Design and Verification

Project Overview

This project implements a 4-bit Arithmetic Logic Unit (ALU) reference model in Python. It demonstrates basic digital logic operations and verification techniques.

Supported Operations

Operation	Description
ADD	Addition
SUB	Subtraction
AND	Bitwise AND
OR	Bitwise OR
XOR	Bitwise XOR

Verification Features

* Python reference model
* Automated functional checks
* Randomized testing
* Boundary-value testing
* Functional coverage of supported operations

Technologies

* Python
* Google Colab
* Verilog RTL (in progress)

Project Status

The Python reference model and verification tests have been developed. Verilog simulation and integration are in progress.

Learning Objectives

* Understand ALU functionality
* Practice Python programming
* Develop verification test cases
* Build a foundation for RTL design and Design Verification
